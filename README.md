# ForestDESK

ForestDESK \- легковесное кроссплатформенное приложение для удаленного доступа к рабочему столу. Проект ориентирован на русскоязычных пользователей и будет полностью локализован на русский язык.

## Начало работы

1. Установите CMake не ниже версии 3.10 и компилятор с поддержкой C++17.
2. Склонируйте репозиторий и выполните сборку:

```bash
cmake -B build
cmake --build build
```
3. Запустите собранное приложение:

```bash
./build/forestdesk
```

## Структура репозитория

- `src/` \- исходный код приложения.
- `resources/` \- будущие ресурсы и файлы локализации.
- `docs/` \- документация проекта на русском языке.

Данная структура будет расширяться по мере разработки.
