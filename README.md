# ForestDESK

ForestDESK — это проект для управления данными лесных угодий и моделирования процессов.

## Сборка

1. Установите `CMake` и компилятор C++17.
2. В каталоге проекта выполните:
   ```bash
   cmake -S . -B build
   cmake --build build
   ```
3. Полученный исполняемый файл появится в папке `build/`.
